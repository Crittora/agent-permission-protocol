# Versioning

The Agent Permission Protocol is versioned to preserve semantic clarity and enable precise reference.

Current version: **v0.2.0**.

Versioning policy:

- Patch releases (`0.2.x`) are reserved for editorial clarification and non-normative publication corrections.
- Minor releases (`0.x.0`) may refine normative semantics, required fields, or verifier obligations.
- Major releases (`1.0.0` and beyond) signal a stable baseline with explicit backward-compatibility commitments.

Changes between versions are documented in the changelog.
